# Tradeup

**Tradeup** is a **trading application** built for **traders at every level** — from first steps to advanced workflows — with a focus on a clear, dependable experience around accounts, markets, and execution. This repository hosts the product as a **monorepo**: a **mobile app** and an **API**, wired for real-world data, auth, and scale as features land.

The first end-to-end slice is a **Mini Binance–style learning stack** (BRL/BTC wallet, quotes, buy/sell, history).
